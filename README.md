# Networking Notes for Cybersecurity

Personal documentation of networking concepts learned during 
my cybersecurity journey.

## Purpose
This repository documents my understanding of networking 
fundamentals from a cybersecurity perspective. These notes 
combine theoretical knowledge from my DCN course, Google 
Cybersecurity Certificate, and NetworkChuck's CCNA playlist.

## Environment
- Practical tools: Wireshark, tcpdump, nmap
- Platform: Kali Linux
- Focus: Blue Team and SOC Analyst perspective

## Topics Covered
- OSI Model and TCP/IP Model
- TCP/IP protocols and communication
- Protocols and port numbers
- Network devices and their security implications
- DNS and DHCP
- Network security concepts

## Learning Resources
- Google Cybersecurity Professional Certificate
- NetworkChuck CCNA playlist
- DCN (Data Communication Networks) university course
- TryHackMe Pre-Security path
